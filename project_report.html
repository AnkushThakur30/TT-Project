📊 Project Overview

The Bus Booking System is a modern, fully-functional web application designed to provide users with a seamless experience for browsing and booking bus tickets. Built with cutting-edge web technologies, the system combines an intuitive user interface with robust backend functionality.

This project demonstrates a complete booking management solution with persistent data storage, responsive design, and professional user experience. The system is designed for easy deployment and scalability, with both web-based and C++ desktop implementations available.

✨ Key Features

🚌 Bus Management

Browse comprehensive bus information including routes, departure times, duration, prices, and amenities with high-quality images.

📱 Responsive Design

Fully responsive interface that works seamlessly on desktop, tablet, and mobile devices with adaptive layouts.

🎫 Booking System

User-friendly booking interface with customer details validation and automatic price calculation for multiple seats.

💾 Data Persistence

Browser localStorage integration for saving bookings locally without server-side requirements for demo purposes.

📊 Booking Management

View all bookings with detailed information including customer name, email, travel date, seats, and booking ID.

💰 INR Currency

All prices displayed in Indian Rupees (₹) with accurate calculations and formatting throughout the application.

🚀 Usage Guide

Web Version (Browser)

Step 1: Open the Application

Open index.html in your web browser to access the Bus Booking System.

Step 2: Navigate Sections

Use the navigation menu to browse: Home, Buses, and My Bookings sections.

Step 3: Select a Bus

Click on any bus card to view detailed information and amenities.

Step 4: Book Your Ticket

Click "Book Now" to open the booking form and enter your details.

Step 5: Confirm Booking

Fill in name, email, date, and number of seats. Click "Confirm Booking".

Step 6: View Bookings

Go to "My Bookings" to see all your confirmed reservations.

C++ Desktop Version (Qt)

Prerequisites:

  • Qt 5.12 or higher installed
  • C++11 compatible compiler
  • SQLite support (included with Qt)
Step 1: Open Qt Creator

Launch Qt Creator and open the CppBookingSystem.pro file.

Step 2: Configure Project

Select a Desktop Qt kit and configure for your platform.

Step 3: Build Project

Go to Build menu and select "Build Project".

Step 4: Run Application

Click Run button or press Ctrl+R to launch the desktop application.
